# Pizza Sales Analysis 🍕

## Project Overview
This project uses **Python** to analyze pizza restaurant sales data. The goal is to identify trends, top-selling products, and revenue insights to help make data-driven business decisions.

## Tech Stack
* **Python** (Core Language)
* **Pandas** (Data Analysis)
* **Matplotlib & Seaborn** (Data Visualization)
* **Jupyter Notebook** (Development Environment)

## Key Insights
* **Revenue Trends:** Identification of peak sales months and daily order patterns.
* **Customer Preferences:** Analysis of the most popular pizza sizes and categories.
* **Top Performers:** Ranking pizzas based on total quantity sold and revenue generated.

## Project Structure
* `Pizza_Analysis_Sabareesh.ipynb`: The main notebook containing the data cleaning and analysis code.
* `pizza_sales_data.csv`: The dataset used for this project.

## How to Use
1. Clone the repository.
2. Install dependencies: `pip install pandas matplotlib seaborn`.
3. Open the `.ipynb` file in Jupyter or VS Code to see the results.
